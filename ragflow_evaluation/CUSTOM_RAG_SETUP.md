# Custom RAG with Integrated Evaluation - Complete Setup

## ✅ What Has Been Built

A notebook-based RAG evaluation pipeline with:

### 1. **Multiple Embedding Models**
- OpenAI text-embedding-3-small (1536 dims)
- Mistral via HuggingFace
- Snowflake Arctic Embed Large (1024 dims)
- BAAI BGE Large EN v1.5 (1024 dims)

### 2. **Reranking Support**
- FlashRank (fast, production-ready)
- BGE Reranker (optional, higher quality)

### 3. **Complete Pipeline**
- Document ingestion with chunking
- Separate vector stores per embedding model
- Similarity search with top-k retrieval
- Reranking to improve relevance
- Answer generation with LLM
- Integrated Ragas evaluation

### 4. **Monitoring & Comparison**
- Per-query metrics tracking
- Real-time performance monitoring
- Cross-model comparison
- Detailed visualizations

## 📊 Evaluation Flow

```
For each test question:
  For each embedding model:
    1. Embed question
    2. Similarity search → top-10 chunks
    3. Rerank with FlashRank → top-5 chunks
    4. Format prompt with contexts
    5. Generate answer with GPT-4o-mini
    6. Calculate Ragas metrics:
       - Context Precision
       - Context Recall
       - Faithfulness
       - Answer Relevancy
    7. Save intermediate results
  Next model
Next question

Final: Aggregate and compare all models
```

## 🔧 Configuration Options

Edit `src/custom_rag_config.py` to adjust:

### Retrieval Settings
```python
RETRIEVAL_CONFIG = {
    "top_k": 10,                  # Initial retrieval count
    "top_n_after_rerank": 5,      # After reranking
    "use_reranking": True,        # Enable/disable reranking
    "similarity_threshold": 0.5   # Minimum similarity
}
```

### Chunking Settings
```python
CHUNKING_CONFIG = {
    "chunk_size": 500,      # Adjust for longer/shorter chunks
    "chunk_overlap": 50,    # Overlap between chunks
}
```

### LLM Settings
```python
GENERATION_LLM = {
    "model": "gpt-4o-mini",     # Or "gpt-4o" for better quality
    "temperature": 0.1,
    "max_tokens": 500
}
```

### Embedding Models
Add/remove models in `EMBEDDING_MODELS` list.

## ❓ FAQ

**Q: Why separate vector stores?**
A: To ensure fair comparison - same chunks, only embedding changes.

**Q: Can I skip reranking?**
A: Yes, set `use_reranking=False` in config.

**Q: Can I add more embedding models?**
A: Yes, edit `EMBEDDING_MODELS` in config and re-run ingestion.

**Q: How long does ingestion take?**
A: 10-30 min depending on model downloads. One-time only.

**Q: How long does evaluation take?**
A: ~20 min for 20 questions × 4 models (varies with API speed).

**Q: Can I use GPU?**
A: Yes, change `'device': 'cpu'` to `'device': 'cuda'` in config.

**Q: Where are costs?**
A: OpenAI API only (embeddings + Ragas evaluator). HuggingFace models are free.
