## 📊 Evaluation Pipeline

```
For each test question (20 total):
  For each embedding model (4 total):

    1. RETRIEVE
       ├─ Embed question with model
       ├─ Similarity search in vector store
       └─ Get top-10 chunks

    2. RERANK
       ├─ Apply FlashRank reranker
       └─ Select top-5 chunks

    3. GENERATE
       ├─ Format prompt with contexts
       ├─ Call GPT-4o-mini for answer
       └─ Return generated answer

    4. EVALUATE (Ragas)
       ├─ Context Precision (are retrieved chunks relevant?)
       ├─ Context Recall (did we find the right contexts?)
       ├─ Faithfulness (is answer grounded in context?)
       └─ Answer Relevancy (is answer relevant to question?)

    5. SAVE
       └─ Store results immediately

Final: Compare all 4 models
```

## ⚙️ Customization

### Adjust Retrieval Settings

Edit `src/custom_rag_config.py`:

```python
RETRIEVAL_CONFIG = {
    "top_k": 10,                  # Change initial retrieval count
    "top_n_after_rerank": 5,      # Change final context count
    "use_reranking": True,        # Disable to skip reranking
}
```

### Change Chunking

```python
CHUNKING_CONFIG = {
    "chunk_size": 500,      # Increase for longer chunks
    "chunk_overlap": 50,    # Adjust overlap
}
```

### Change LLM

```python
GENERATION_LLM = {
    "model": "gpt-4o",          # Use GPT-4o for better quality
    "temperature": 0.1,
}
```

### Add More Embedding Models

Add to `EMBEDDING_MODELS` list in config:

```python
{
    "name": "new_model",
    "display_name": "New Model Name",
    "provider": "openai",  # or "huggingface"
    "model": "model-name",
    "dimensions": 768,
    "collection_name": "uso_new_model",
    "description": "Description"
}
```

Then re-run ingestion notebook.

## 💰 Cost Estimate

### One-Time Ingestion
- **OpenAI embeddings**: ~600 chunks × $0.00002/1k tokens ≈ **$0.01**
- **HuggingFace models**: **FREE** (local)

### Per Evaluation Run (20 questions × 4 models)
- **Answer generation**: 80 queries × GPT-4o-mini ≈ **$0.05**
- **Ragas evaluation**: 80 × 4 metrics × GPT-4o-mini ≈ **$0.20**
- **Total per run**: ~**$0.25**

### Cost Saving Tips
- Use `gpt-4o-mini` (current setting) instead of `gpt-4o`
- Use HuggingFace models (free) instead of OpenAI
- Reduce test dataset size for quick tests

## 🔧 Troubleshooting

### Issue: HuggingFace model download fails

**Solution:**
```bash
# Download models manually first
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('BAAI/bge-large-en-v1.5')"
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('Snowflake/snowflake-arctic-embed-l')"
```

### Issue: ChromaDB errors

**Solution:** Delete and recreate vector stores
```bash
rm -rf data/vector_stores/*
# Then re-run ingestion notebook
```

### Issue: Out of memory

**Solution:** Process fewer models at a time
- Comment out some models in `EMBEDDING_MODELS`
- Or reduce `chunk_size` in config

### Issue: Ragas evaluation slow

**Expected:** Each question takes ~10-15 seconds (4 metrics × LLM calls)

**Speed up:**
- Use fewer test questions
- Disable some metrics in evaluation notebook
